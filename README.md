# Smart Buffer

Click up to 2/4/6/8/10/12/14/16 ticks early; the click is re-fired on the exact tick it becomes useful.

## Build
    export GEODE_SDK=/path/to/geode/sdk
    geode build        # or: cmake -B build && cmake --build build --config RelWithDebInfo

Change `id` / `developer` in mod.json before building.
